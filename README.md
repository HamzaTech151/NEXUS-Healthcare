# 🏥 NEXUS Healthcare

**Live Demo:** [https://hamzatech151.github.io/NEXUS-Healthcare/](https://hamzatech151.github.io/NEXUS-Healthcare/)

A premium, fully responsive healthcare website designed to provide a modern, user-friendly experience for patients and healthcare providers.

---

## ✨ Features

### 🏠 Home & Navigation
- Sticky Navigation with smooth scroll
- Animated Hero Section with floating medical icons
- Animated Background with floating particles
- Interactive Stats Counter (Patients Treated, Satisfaction Rate, Specialties)

### 🏥 Services
- Expandable Service Accordion with 6 comprehensive healthcare services
- Detailed Information for each service with features list
- Quick Contact links for each service

### 🏛️ Departments
- 2×6 Grid Layout showing 12 medical departments
- Interactive Cards with hover effects
- Color-coded by department

### 📅 Appointment Booking
- Interactive Calendar with month navigation
- Time Slot Selection for appointments
- Patient Details Form with validation

### 📰 Blog Section
- 3 Health Articles with categories (Cardiology, Neuroscience, Pediatrics)
- Author & Date information
- Read More functionality

### 📚 Patient Education
- 4 Resource Cards (Health Guides, Video Library, Downloadable Resources, FAQ)
- Interactive Modals with detailed content

### 💼 Careers
- 3 Job Listings with Apply Now functionality
- Full Application Form with validation
- Resume Upload functionality
- Professional Success Modal with Application ID

### ⭐ Testimonials
- Interactive Carousel with 5 patient reviews
- Auto-play functionality
- Navigation Controls (Previous/Next, Dots)
- Touch Support for mobile devices

### 💬 AI Chat Assistant
- Floating Chat Widget with AI responses
- Quick Options (Book Appointment, Emergency Help, Find a Doctor)
- Real-time Messaging interface

### 📞 Contact Section
- Split Layout with contact info and form
- Form Validation with loading states
- Success Confirmation modal

### 🎨 Additional Features
- Preloader Animation for better UX
- Back to Top Button with smooth scroll
- Custom Scrollbar styling
- Fully Responsive Design for all devices
- Accessibility features (ARIA labels, skip link)
- SEO Optimized with meta tags and structured data

---

## 🛠️ Technologies Used

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, CSS Grid, Animations
- **JavaScript (Vanilla)** - ES6+, DOM manipulation, Event handling

### Libraries & Tools
- **Font Awesome 6** - Premium icons
- **Google Fonts** (Inter & Playfair Display)
- **Git & GitHub** - Version control
- **GitHub Pages** - Deployment

### Design Patterns
- **Mobile-First Approach**
- **BEM-like Methodology** for CSS
- **Modular JavaScript** with IIFE pattern
- **Glassmorphism** design effects
